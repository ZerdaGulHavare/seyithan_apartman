# 🏠 Seyithan & Hamit Apartman Sitesi

Hatay Serinyol'da bulunan kiralık daireler için geliştirilmiş; performans odaklı, modern ve kullanıcı dostu bir tanıtım platformudur.

## ✨ Öne Çıkan Özellikler

- **📱 Tam Responsive Yapı:** Mobile-first yaklaşımıyla tüm cihazlarda kusursuz görüntüleme.
- **⚡ Dinamik İçerik Yönetimi:** JavaScript DOM manipülasyonu ile sayfa yenilenmeden apartlar arası akıcı geçiş.
- **🔍 Akıllı İçerik Optimizasyonu:** Ekran boyutuna göre değişen akıllı metinler (Örn: Mobilde detaylı "Full Eşyalı", Web'de sade "Full" görünümü).
- **💬 Hızlı İletişim:** Entegre WhatsApp API yönlendirmeleri ile anlık rezervasyon imkanı.
- **🎨 Minimalist UI/UX:** Temiz kod yapısı ve modern tasarım prensipleri.

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Semantik etiketleme ile SEO uyumlu altyapı.
- **CSS3:** Flexbox, CSS Grid ve gelişmiş Media Queries.
- **JavaScript (ES6+):** İnteraktif bileşenler ve dinamik içerik yönetimi.
